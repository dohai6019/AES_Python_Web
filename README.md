# AES-256 Encryption and Decryption using Python

## 1. Giới thiệu

Đây là chương trình minh họa thuật toán mã hóa đối xứng AES
được cài đặt bằng ngôn ngữ lập trình Python.

Chương trình thực hiện mã hóa và giải mã dữ liệu bằng thuật toán
AES-256 ở chế độ CBC.

## 2. Chức năng

- Nhập dữ liệu cần mã hóa
- Mã hóa dữ liệu bằng AES-256
- Tạo IV ngẫu nhiên
- Hiển thị dữ liệu đã mã hóa
- Giải mã dữ liệu
- Kiểm tra dữ liệu sau khi giải mã

## 3. Công nghệ sử dụng

- Python 3
- PyCryptodome
- AES-256
- CBC Mode
- Base64
